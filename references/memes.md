# 可爱梗与续作去重

用于“来点梗”“再来一套”“不要重合”。目标是聊天时能用、角色仍可辨认、文字不占满画面。

## 选梗

先查已有历史，再设计新方案。优先选择能通过具体姿势表达的日常反应，例如悄悄请求、郑重递礼物、踮脚够东西、抱紧小物件、忙碌敲键盘。道具为动作服务，不给每格硬塞复杂背景。

下列只是候选表达，不是热度榜，也不应每次照抄：

| 表达方向 | 文案候选 | 画面思路 |
| --- | --- | --- |
| 想加入 | “带我一个” | 踮脚努力挤进画面，举着小手 |
| 小心请求 | “可以嘛” | 身体前倾、两手捧着空盘子 |
| 真诚回应 | “听你的” | 坐得笔直，认真拿小本子 |
| 送出祝福 | “接好运” | 双手递出简洁的小幸运袋 |
| 小小得意 | “拿捏” | 认真调整一副过大的墨镜 |
| 想要奖励 | “求夸夸” | 展示刚完成的小作品 |

角色锚点优先；不要为了套某个梗，把人物直接替换成另一套知名角色设计。

用户要求“最近／主流／最火”时，或不确定梗的含义、语气、来源时，使用可用检索确认；没有检索能力时说清楚按通用表达设计，不编造热度。梗介绍尽量引用实际讨论或可靠报道，避免把搜索摘要里的营销盘点当成严格排名。交付图片不需要附长篇梗史。

## 三层去重

| 层次 | 要比较什么 | 常见漏判 |
| --- | --- | --- |
| 文案 | 原文、同义词、同音改写 | “收到”换成“收到啦” |
| 动作语义 | 手势、表情与使用场景 | “比心”和“爱你”仍然都在手指比心 |
| 构图与道具 | 人物姿势、视角、主道具 | 同一个喝咖啡姿势只换杯子颜色 |

角色重复是保持系列一致；动作和聊天用途高度重合才是这里的重复。文字不同不能自动认定是新梗。用户说“别重合”时，同时避开文字与主要动作；用户明确要同一动作变体时则按变体执行。

先写九格候选，逐项对历史比对，再确认九格内部也不重复。不要为凑九格安排“吃草莓”和“偷吃饼干”这种用途过近的两个动作，除非用户需要食物主题套组。

## 追加到九宫格提示词

```text
这是一套续作，保持角色和画法一致。
本次可用文案：<列表>；只在 <格号> 使用，其余无字。
已使用、需要避开的表达与动作：<从历史中归纳的短清单>。
本次九格有不同的聊天用途和主动作。不要仅更换文字或道具颜色来复用旧姿势。
```

看成图后再进行一次对比：生成结果会偏离预案。重复或错字时局部修正；完成后将实际结果追加到输出目录的 `sticker-history.json`。
