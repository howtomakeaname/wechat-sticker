# 拆片与去背景：九宫格 → 独立透明表情

把一张 3×3 合集图变成九张可直接使用的透明底单片。分两步：先裁（`split-grid`），再抠（`scripts/sticker_cutout.py`）。裁切不等于抠图；抠图也不保证边缘质量，必须看图验收。

## 适用前提

本方法针对本工作流生成的版式：近似均匀的浅色卡片底（如浅蓝），主体带浅色/白色描边。原理是「从图片边缘向内的背景色连通区域泛洪」，因此：

- 背景必须大致均匀且与主体有色差。复杂场景、渐变照片背景不适用。
- 被主体轮廓**完全包住**的背景色区域（如头发高光、卡片内浅色底）不会被误删——它们不与图片边缘连通。
- 文字、问号、爱心、汗滴等独立小元素与主体不连通也会被保留；不要只保留最大连通块。

## 流程

```bash
# 1. 裁九格；数学等分只是起点，先逐格看图
python3 scripts/image_assets.py split-grid SHEET.png output/tiles

# 2. 逐格抠图，同时输出棋盘格预览
python3 scripts/sticker_cutout.py output/tiles/sticker-01.png output/cutout/sticker-01.png \
    --preview output/preview/sticker-01.png

# 3. 属性检查（不能代替看图）
python3 scripts/image_assets.py check output/cutout/sticker-01.png --require-transparent
```

真实九宫格里呆毛、装饰、文字常伸出格子边界。先查看格间空隙：若某格的呆毛伸进了上一格，用 `--boxes` 调整裁切框——上一格底部少裁、下一格顶部多裁，把伸出的部分还给它所属的格子。跨格内容被切断或张冠李戴是真实发生过的失败。

## 已知失败模式与对策

| 现象 | 原因 | 对策 |
| --- | --- | --- |
| 头发/高光被抠出缺口 | 白边有缺口，背景色泛洪"渗漏"进主体 | 加大 `--erode`（默认 2，可试 4），利用腐蚀先封住窄缺口再泛洪 |
| 浅色道具整个消失（抱枕、袖子） | 道具与背景同色且直接贴到裁切边缘，与外部背景连通 | 用 `--protect x0,y0,x1,y1`（输入图坐标，可多次）框住道具区域强制保留，抠后检查框内是否带入残留底色 |
| 底部/边缘残留白框条、碎屑 | 卡片白框不是背景色，泛洪删不掉 | 重新裁切去掉框外内容；零散碎屑在预览中确认后用图像编辑工具定点清理 |
| 边缘一圈背景色光晕 | 泛洪边界停在抗锯齿过渡带上 | 默认已收缩 1px 并羽化；仍有光晕时加大 `--grow` 或在预览中确认后复抠 |
| 输出几乎全透明 | 主体颜色与背景过近被误吞 | 不要用更宽的阈值硬抠；检查 `--blue-diff`/`--min-blue`，必要时换方法并明确报告 |

`--protect` 是区域修复手段，不是遮罩抠图：框内与背景同色的区域会整体保留，框选要紧贴道具。

## 验收

1. 每张都过 `check --require-transparent`，确认存在真实透明像素与可见内容。
2. 在棋盘格或深浅底色预览上逐张看：白/蓝光晕、锯齿、发丝、文字笔画、道具完整性。预览图只用于检查，不进入交付。
3. 与九宫格原图逐格对照：装饰符号（"川"字线、感叹号、音效线）最容易被漏删或误删。
4. 记录每张的裁切框与所用参数（`--erode`、`--protect`），视觉验收通过才算完成；数值检查通过不算。

## 与封面的关系

封面要求的「无白描边」不适用于普通单片：本工具保留主体自带的浅色描边，这是贴纸风格的一部分。封面若需要无描边轮廓，需在生成阶段避免描边，或在抠图后另行处理，见 [cover.md](cover.md)。
