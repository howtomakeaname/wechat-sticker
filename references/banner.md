# 表情合集宣传横幅

默认交付 **750×400 像素 PNG**，横向比例 **15:8**。此尺寸来自案例请求；用户要求其他规格时覆盖。

## 设计选择

主角色承担辨识度，辅以少量表情预览。根据构图选择角色与标题位置；不需要每张都固定左人右字。标题使用专辑名；未命名时可用“表情包合集”，不要擅自给角色起永久名字。

适合这类尺寸的布局：一个清晰主视觉、一块标题区域、2–3 枚较小表情预览。保留安全边距，面部和文字避免贴边；背景细节在缩到 750×400 后不应抢过角色。

本类通常采用不透明设计背景，不继承封面的透明要求。

## 提示词模板

```text
任务：制作表情专辑宣传横幅，目标交付 750×400 PNG，构图比例 15:8。
参考图：图 1 为角色身份，图 2 为已有表情的画风与配色。
主视觉：<角色锚点>，<主动作>。
布局：<主角色、标题、少量表情预览的关系>。
背景：<与专辑一致的简洁背景>。
唯一标题，逐字照写：“<标题>”。字形清楚，缩到目标尺寸仍可读。
所有面部、标题和关键手势放在安全范围内，为精确等比裁切留出边距。
不要把九宫格缩成一张横图；应是一张完整的横向宣传设计。
```

## 精确导出

生成工具返回的实际分辨率未必等于提示词目标。先看图，再从下面选一种：

- 比例已接近且边缘可裁：等比缩放填满，再裁切为 750×400。
- 裁切会伤到脸或标题：等比适配完整构图，并以设计背景填充边缘，或重新调整构图。

不要直接不等比压缩人物。生成后的缩小是重采样，不能描述为“无损缩放”。

```bash
python3 scripts/image_assets.py export INPUT.png OUTPUT.png --profile banner
python3 scripts/image_assets.py check OUTPUT.png --profile banner
```

导出后查看实际大小下的成图，确认字形、边距和脸部没有被裁断。脚本只能检查文件属性，无法替代视觉验收。
