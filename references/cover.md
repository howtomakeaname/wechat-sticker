# 表情专辑封面

用于艺术家主页列表展示的代表图。下面规格来自案例中用户给出的提交要求；用户提供新版本时优先采用。

| 项目 | 预设 |
| --- | --- |
| 文件 | PNG，240×240 像素 |
| 背景 | 真实透明背景，不用白色背景 |
| 主体 | 最具辨识度的正面半身或全身，避免只有头部 |
| 轮廓 | 无额外白色描边，边缘平滑 |
| 内容 | 简洁、少留白，避免装饰和文字 |
| 文件大小 | 大于 500KB 可能被平台压缩；这是一条提醒，不是自动判为无效 |
| 专辑区分 | 不同专辑选择不同姿势或构图 |

可保留角色本来就有的白色头发、白色服装；“无白描边”指轮廓外的贴纸边框。不要为了去白边删除角色自身的白色区域。

## 提示词模板

```text
任务：制作表情专辑封面，正方形，最终用于 240×240 PNG。
角色参考：<图片与角色锚点>。
姿势：正面<半身/全身>，<能代表角色的简洁动作>；清楚显示身体。
画法：<已接受的 Q 版风格>，平滑边缘、清晰轮廓。
构图：主体居中，充分占用画布，四周少量安全边距，关键部位完整。
背景：输出实际带透明像素的 PNG；角色外像素透明，不绘制棋盘格。
画面仅保留主体和动作必需的简洁道具。
无文字、无额外装饰、无边框、无白色贴纸描边、无外发光。
保留角色自己的白色头发和白色衣服。
```

## 透明度失败的处理

1. 先检查实际像素，不能通过预览中的棋盘格判断透明。没有透明像素，或整张图全透明，都不合格。
2. 看工具是否支持真实 Alpha 输出；能力可用时，对背景做一次有针对性的修正，并保持角色锚点。
3. 同类失败持续出现时不要无限重复强调“透明”。使用当前环境支持且已授权的抠图／蒙版流程，或在没有合适能力时明确报告透明导出未完成。更换服务、计费或账号遵守宿主授权规则。
4. 抠图不得用全局“白色变透明”处理白发、白衣角色。需要分离背景与前景，并保留发丝、轮廓和半透明抗锯齿像素。

`image_assets.py` 的导出命令**不负责抠图**。它会拒绝从不透明输入导出封面，避免只在外面加一圈透明像素就伪装通过。九宫格单片的卡片底可用 `sticker_cutout.py` 去除（见 [拆片与去背景](cutout.md)），但它保留主体自带的浅色描边，不满足封面「无白描边」的要求；封面主体仍需在生成阶段避免描边。

```bash
python3 scripts/image_assets.py export TRANSPARENT_SOURCE.png cover.png --profile cover
python3 scripts/image_assets.py check cover.png --profile cover
```

脚本会裁去纯透明空边、等比缩放并加入默认 3 像素安全边距，不改变角色外形。视觉上再确认无白边、无残留棋盘格、没有大量留白、缩小后眼睛与饰品清楚。真实 Alpha 与残留的不透明背景可能同时存在，因此数值通过仍须看图。
